# Bristol-Regional-Food-Network

### Running Instructions

1. docker compose up --build (in first terminal)

2. docker compose web exec bash (in second terminal)

3. python manage.py migrate (in second terminal)

4. python manage.py loaddata app_complete_dump.json (in second terminal)

5. Open the browser on http://localhost:8000/ 

6. **Note:** Make sure everything in requirements.txt has been successfully installed.
